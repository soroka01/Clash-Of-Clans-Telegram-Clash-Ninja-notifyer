# JSON-аккаунты

В режиме `"data_source": "json"` положите сюда отдельный JSON-файл для каждого аккаунта.

Поддерживается исходный экспорт из игры без каких-либо изменений. Просто сохраните или вставьте полный JSON-код аккаунта в файл с ником до `.json`, например:

```text
Greatness.json
```

Имена файлов могут быть любыми: `Greatness.json`, `luv_u_my_cutie.json`, `soroka01.json`.
